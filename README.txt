Organigastos — diseño cálido v3

Archivos: index.html, manifest.json, sw.js.
Subí estos tres archivos a la raíz del repositorio de GitHub Pages y hacé Commit changes.

Para evitar ver la versión anterior:
1. Esperá a que GitHub Pages termine de publicar.
2. En iPhone, cerrá la pestaña de la app.
3. Abrí la URL en Safari y recargá.
4. Si sigue igual, probá abrir la URL en una pestaña privada para verificar la versión nueva.
5. Si la instalaste como icono, eliminá el icono anterior y volvé a añadirlo desde Safari.

Los datos se guardan localmente en el navegador. No se sincronizan entre dispositivos. Antes de cambiar de URL/navegador, exportá un respaldo si ya registraste movimientos.
